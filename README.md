# Yannick Gloster - Portfolio

A modern, performant portfolio website built with Next.js 16, shadcn/ui, and Tailwind CSS.

## Quick Start

```bash
# Install dependencies
bun install

# Start development server
bun run dev

# Build for production
bun run build

# Start production server
bun run start
```

Visit `http://localhost:3000` to view the site.
